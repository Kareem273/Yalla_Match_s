Design a modern, premium Admin Dashboard UI for a sports court reservation system called "Yalla Match".

This is a UI prototype only, but it should be fully interactive with mock data as if the application is already running.

Theme:
- Primary Color: Red (#D32F2F)
- Secondary Color: White (#FFFFFF)
- Background: Light Gray (#F5F5F5)
- Cards: White with soft shadows
- Border Radius: 16px
- Modern dashboard similar to Stripe, Notion, Vercel and Linear.
- Clean, minimal and responsive.
- Use Material Design 3.
- Desktop-first design.
